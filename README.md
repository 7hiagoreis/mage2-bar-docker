### mage2-bar-docker

O projeto `mage2-bar-docker` foi desenvolvido na plataforma Magento 2, utilizando Docker. O projeto é voltado para bares, com catálogo simples de bebidas, petiscos e fechamento de pedidos localmente.


### Objetivo

Executar o **Magento 2** em containers Docker, simulando a operação de um bar e utilizando o projeto também como laboratório para aplicação de conceitos de infraestrutura e DevOps.

O ambiente permite trabalhar com containers, infraestrutura como código, automação e versionamento.


---


### Tecnologias utilizadas no projeto
- Docker & Docker Compose
- Debian 13
- Nginx + PHP-FPM 8.2
- Magento 2 Community Edition
- MariaDB/MySQL
- Opensearch
- Redis
- IaC (Terraform)
